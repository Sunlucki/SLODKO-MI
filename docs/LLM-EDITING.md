# Редактирование сайта с помощью любого LLM

Весь сайт SŁODKO MI — тексты, ссылки, фото, вкусы, часы работы, SEO, **порядок блоков на страницах** и переводы на
английский, русский и украинский — хранится в JSON-файлах в `src/data/`. Код трогать не нужно: нейросеть меняет JSON,
проект сам проверяет правку (схемы, существование фото, ссылок и вкусов, правила переводов) и не даёт сохранить
сломанный контент.

Пишите инструкции **по-русски или по-польски**. Польские файлы модель пишет по-польски, переводы — на языке перевода.

| Способ | Когда удобно | Что нужно |
| --- | --- | --- |
| [1. Агент в репозитории](#1-агент-в-репозитории) — Claude Code, Cursor, Codex, Copilot | большие правки, новые блоки, код | редактор/терминал |
| [2. MCP-сервер](#2-mcp-сервер) — Claude Desktop, Cursor, VS Code, Windsurf | правки в чате с безопасными инструментами | Node.js + проект на компьютере |
| [3. Команда `npm run ai`](#3-команда-npm-run-ai) — Anthropic, OpenAI, OpenRouter, Ollama… | быстрые правки одной фразой | терминал + API-ключ |
| [4. GitHub Action](#4-github-action-с-телефона) | с телефона, без компьютера | аккаунт GitHub |
| [5. ChatGPT / любой чат](#5-chatgpt-или-любой-чат) | нет API-ключа, есть подписка на чат | браузер |

## Что где лежит

| Что | Файл |
| --- | --- |
| Название, телефон, адрес, вход с Hetmańskiej, часы, ссылки (Wolt, Instagram, Google), меню, футер, цвета, баннер cookies | `src/data/site.json` |
| Особые дни: праздники, закрыто, другие часы на конкретную дату | `src/data/site.json` → `specialHours` |
| Подписи интерфейса: «Alergeny», «Skład», «Inne smaki», страница 404, «Otwarte teraz», «Pokaż mapę», «Czytaj całość»… | `src/data/site.json` → `ui` (необязательно: по умолчанию польские тексты из схемы) |
| Вкусы: названия, описания, цены, аллергены, фото, «Bestseller», SEO-заголовок страницы вкуса | `src/data/products.json` |
| Страницы: каждая — файл `src/data/pages/<имя>.json` (главная — `home.json`) со списком блоков `sections` | `src/data/pages/` |
| Переводы (EN, RU, UK): только тексты, те же имена файлов | `src/data/i18n/en/`, `ru/`, `uk/` |
| Отзывы Google (обновляются автоматически раз в неделю — руками и нейросетью не править, инструменты их не меняют) | `src/data/reviews.json` |
| Описание всех полей и типов блоков с примерами | `docs/CONTENT-REFERENCE.md`, `schema/README.md` |
| Пошаговые рецепты (часы, вкус, цены, страница, язык, фото, пиксели, деплой) | `docs/RECIPES.md` |
| Правила переводов | `docs/I18N.md` |
| Правила для нейросетей | `AGENTS.md` |

**Типы блоков** (`type`): `hero` (первый экран), `about`, `split`, `productGrid` (сетка вкусов), `reviews`, `visit` (адрес,
часы, карта), `gallery`, `faq`, `cta` (баннер с кнопками), `text`. Блок скрывается полем `"enabled": false`, порядок
блоков = порядок в массиве. Новый файл в `src/data/pages/` = новая страница сайта (сразу на всех языках). Если скрытый
блок указан в меню или футере, ссылку нужно убрать или поменять в той же правке — иначе проверка не пропустит. Поля
строго по схеме: опечатка в названии поля (`"visible"` вместо `"enabled"`) — ошибка, а не тихо проигнорированная правка.

**Ссылки-токены** вместо адресов: `@order` (Wolt), `@phone`, `@directions` (маршрут), `@instagram`, `@facebook`, `@reviews`,
`@writeReview`. Они берут адреса из `site.json`, и клики по ним автоматически считаются в аналитике.

**Фото** указываются ключом (`products/oreo`, `photos/zespol`). Новое фото: положить файл в `assets/images/<папка>/<имя>.jpg`
и выполнить `npm run images` (или инструмент `add_image` в MCP). Картинки, сгенерированные нейросетью, помечаются
`"aiGenerated": true` — на сайте на них видна подпись «Ilustracja».

**Переводы** — это «накладки» только с текстами: в `src/data/i18n/en/pages/home.json` лежат те же ключи, что в польском
`src/data/pages/home.json`, но только переведённые строки. Структура (порядок блоков, ссылки, фото, цены, часы) всегда
берётся из польского файла. Чего нет в переводе — показывается по-польски. Подробно: `docs/I18N.md`.

### Примеры инструкций

- «Поменяй часы работы: в субботу и воскресенье с 10 до 17»
- «В субботу 31.10 закрыто, в четверг 29.10 открываемся в 10:30» (попадёт в `specialHours`, на сайте видно за 14 дней)
- «Добавь новый вкус „Pistacja z białą czekoladą“ с фото cutouts/pistacja, аллергены: глютен, молоко, яйца, орехи»
  (фото сначала положите в `assets/images/cutouts/pistacja.png` и выполните `npm run images`)
- «Сделай „Malina z kokosem“ бестселлером и поставь её первой в сетке вкусов»
- «Перенеси блок с отзывами сразу после первого экрана и скрой галерею»
- «Добавь в FAQ вопрос, можно ли прийти с собакой — ответ: да, конечно» (и тут же: «…и переведи его на все языки»)
- «Создай страницу „Zamówienia na eventy“ по адресу /eventy с текстом и кнопкой звонка, добавь её в меню»
- «Переведи на английский всё, что ещё не переведено»
- «Napisz nowe hasło w hero — bardziej zabawne, w stylu poznańskim»

Нейросеть не придумывает факты: цены, состав, аллергены, калорийность, способы оплаты — только если вы их назвали.

## 1. Агент в репозитории

Claude Code, Cursor, OpenAI Codex, GitHub Copilot (agent mode), Gemini CLI, Aider и другие агенты читают **`AGENTS.md`**
(Claude Code — через `CLAUDE.md`, который его импортирует). Там карта проекта, правила правок, команды и ссылки на
подробные документы в `docs/`.

1. Откройте папку проекта в агенте.
2. Напишите задачу обычным языком — например, «поставь вкус „Malina z kokosem“ первым в сетке и добавь ему значок Nowość».
3. Агент правит JSON и запускает `npm run content:check`. Посмотреть результат: `npm run dev` → http://localhost:5173
   (английская версия — http://localhost:5173/en/).
4. Сделайте commit и push в `main` — сайт опубликуется автоматически (FTP + превью на GitHub Pages).

В Claude Code MCP-сервер из способа 2 подключается сам (файл `.mcp.json`) — при первом запуске согласитесь его включить.

## 2. MCP-сервер

`scripts/content-mcp.ts` — MCP-сервер `slodkomi-content`. Он даёт нейросети безопасные инструменты:

| Инструмент | Что делает |
| --- | --- |
| `list_content` | карта контента: страницы и их блоки, вкусы, меню, фото, языки и полнота переводов, ошибки |
| `get_schema` | JSON-схемы, описание всех типов блоков и правила переводов |
| `read_content` / `write_content` | прочитать / заменить файл целиком (или создать новую страницу или файл перевода) |
| `patch_content` | точечная правка (JSON Patch) — лучший вариант для мелочей и для добавления переводов |
| `delete_page` | удалить страницу вместе с её переводами (кроме главной) или один файл перевода |
| `translation_status` | какие тексты ещё не переведены (язык, файл, путь, польский текст) |
| `validate_content` | проверить весь контент |
| `list_images` / `add_image` | список фото / добавить фото с компьютера (WebP-версии создаются сами) |
| `build_site` | собрать сайт и показать результат |

Писать можно **только** в `src/data/site.json`, `products.json`, `src/data/pages/*.json` и переводы
`src/data/i18n/<язык>/…` (`reviews.json` — только чтение: отзывы обновляет `npm run reviews:fetch`). Каждая запись
проверяется теми же правилами, что и сборка; если правка что-то ломает — файл **автоматически откатывается**, а модель
получает список ошибок и исправляет себя. Если какой-то другой файл контента уже сломан, запись не выполняется, пока
его не исправят.

Перед подключением один раз выполните в папке проекта `npm ci`. Ниже `/ПУТЬ/К/SłodkoMi` — полный путь к проекту
(узнать: `pwd` в папке проекта).

**Claude Code** — уже настроено в `.mcp.json`. Вручную: `claude mcp add slodkomi-content -- npx tsx scripts/content-mcp.ts`.

**Claude Desktop** — Settings → Developer → Edit Config (`~/Library/Application Support/Claude/claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "slodkomi-content": {
      "command": "npx",
      "args": ["-y", "tsx", "/ПУТЬ/К/SłodkoMi/scripts/content-mcp.ts"]
    }
  }
}
```

Если Claude Desktop пишет `spawn npx ENOENT` (так бывает с nvm/Homebrew), укажите node полным путём (`which node`):

```json
{
  "mcpServers": {
    "slodkomi-content": {
      "command": "/opt/homebrew/bin/node",
      "args": ["/ПУТЬ/К/SłodkoMi/node_modules/tsx/dist/cli.mjs", "/ПУТЬ/К/SłodkoMi/scripts/content-mcp.ts"]
    }
  }
}
```

**Cursor** — `.cursor/mcp.json` в проекте или `~/.cursor/mcp.json` (формат как у Claude Desktop, путь — абсолютный).

**VS Code** (Copilot, agent mode) — `.vscode/mcp.json`:

```json
{
  "servers": {
    "slodkomi-content": {
      "type": "stdio",
      "command": "npx",
      "args": ["tsx", "${workspaceFolder}/scripts/content-mcp.ts"]
    }
  }
}
```

**Windsurf** — `~/.codeium/windsurf/mcp_config.json` (формат как у Claude Desktop). **Любой другой MCP-клиент** — stdio-команда
`npx tsx /ПУТЬ/К/SłodkoMi/scripts/content-mcp.ts`.

Начните разговор с «Посмотри контент сайта (list_content) и …». Для переводов: «Посмотри translation_status и переведи
недостающие тексты на украинский». После правок попросите `build_site`, затем закоммитьте и отправьте изменения в
GitHub (терминал или GitHub Desktop) — сайт опубликуется сам.

## 3. Команда `npm run ai`

Одна фраза — и правка готова. Работает с любым LLM: напрямую с Anthropic API или с любым OpenAI-совместимым API.

```bash
npm run ai -- "Добавь в FAQ вопрос про парковку" --dry-run   # показать изменения, ничего не сохраняя
npm run ai -- "Добавь в FAQ вопрос про парковку"             # применить (спросит подтверждение)
npm run ai -- "Скрой галерею" --yes --build                  # без вопросов + сразу собрать сайт
npm run ai -- "Переведи недостающие тексты на английский"    # перевод
```

Как это работает: модель получает правила из `AGENTS.md`, JSON-схемы, правила переводов, список фото и вкусов и все
редактируемые файлы — польские и переводы (кроме отзывов), и отвечает набором JSON Patch-операций. Если в инструкции есть
«переведи / przetłumacz / translate» или назван язык, модель дополнительно получает список непереведённых текстов этого
языка и карту ключевых слов из `docs/SEO-KEYWORDS.md`. Скрипт применяет операции, проверяет весь контент и при ошибке
**откатывает файлы** и отправляет ошибки модели — до 3 раундов исправлений. В конце печатается понятный список изменений
по файлам. На вопрос «Keep these changes?» ответ `n` или Ctrl+C возвращает файлы как были. Предыдущие версии файлов
сохраняются в `.ai-edit-backup/<дата>/`.

Настройки — в `.env.local` (не попадает в git) или в переменных окружения:

```bash
# Anthropic (по умолчанию). Модель по умолчанию — claude-opus-5-5
LLM_PROVIDER=anthropic
LLM_API_KEY=sk-ant-...
# LLM_MODEL=claude-sonnet-5-5   # дешевле;  claude-fable-5-1 — самая сильная и самая дорогая

# OpenAI
LLM_PROVIDER=openai
LLM_API_KEY=sk-...
LLM_MODEL=gpt-5

# OpenRouter (сотни моделей по одному ключу)
LLM_PROVIDER=openai
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_API_KEY=sk-or-...
LLM_MODEL=openai/gpt-5

# Google Gemini (OpenAI-совместимый режим)
LLM_PROVIDER=openai
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai
LLM_API_KEY=...
LLM_MODEL=gemini-2.5-pro

# Ollama — локально и бесплатно (ключ не нужен)
LLM_PROVIDER=openai
LLM_BASE_URL=http://localhost:11434/v1
LLM_MODEL=qwen3:32b

# LM Studio — локально
LLM_PROVIDER=openai
LLM_BASE_URL=http://localhost:1234/v1
LLM_MODEL=<имя загруженной модели>
```

Так же подключаются Groq (`https://api.groq.com/openai/v1`), Mistral (`https://api.mistral.ai/v1`), DeepSeek и любые другие
OpenAI-совместимые сервисы. Названия моделей меняются — актуальные смотрите в списке моделей провайдера.

Полезно знать:

- В запрос уходит весь контент, переводы и схемы — около 200 тыс. символов (порядка 60 тыс. токенов), и он растёт вместе
  с переводами. Повторные раунды дешевле — у Anthropic большая часть запроса кешируется. Размер своего запроса:
  `npm run --silent ai -- --prompt "тест" | wc -c`.
- Локальным моделям нужен контекст от 128 тыс. токенов: для Ollama запускайте `OLLAMA_CONTEXT_LENGTH=131072 ollama serve`,
  в LM Studio увеличьте Context Length в настройках модели. Маленькие модели (7–8B) часто ошибаются — берите 30B+.
- Если модель не может выполнить просьбу одним контентом (нужен новый тип блока, нет нужного фото), она ничего не меняет и
  объясняет, чего не хватает.
- Откатить сохранённую правку: скопируйте файлы из `.ai-edit-backup/<дата>/src/data/` обратно в `src/data/`
  (или `git checkout -- src/data`, если правка ещё не закоммичена).

## 4. GitHub Action с телефона

Правка без компьютера: в приложении GitHub или на github.com.

**Один раз настроить** (Settings репозитория):

1. Secrets and variables → Actions → **New repository secret**: `LLM_API_KEY` — ключ Anthropic (или другого провайдера).
2. Там же, вкладка **Variables** (необязательно): `LLM_PROVIDER` (`anthropic` или `openai`), `LLM_MODEL`, `LLM_BASE_URL` —
   значения как в способе 3.
3. Actions → General → Workflow permissions → включить **Allow GitHub Actions to create and approve pull requests**.

**Каждая правка:**

1. Вкладка **Actions** → слева **AI edit** → **Run workflow**.
2. Впишите, что изменить (по-русски или по-польски; можно «переведи новые тексты на английский»); при желании —
   провайдера и модель. **Run workflow**.
3. Через 2–5 минут появится **Pull request** «AI: …» — в описании итог от модели, список изменений и таблица полноты
   переводов, во вкладке *Files changed* — точный diff. Контент уже проверен, сайт уже собран.
4. Всё хорошо → **Merge pull request**. Workflow **Deploy** сам опубликует сайт (FTP + превью на GitHub Pages).
   Не нравится → **Close pull request**, сайт не изменится.

Можно отправить несколько правок подряд: каждая выполняется отдельно и даёт свой pull request (они не отменяют друг друга).

Если модель не смогла выполнить просьбу, PR не создаётся: её объяснение — в Summary запуска, ошибки проверки — в логе шага
*Edit content with the LLM*.

## 5. ChatGPT или любой чат

**Вариант А — через подготовленный промпт (надёжно).** Нужен проект на компьютере, но не нужен API-ключ:

```bash
npm run ai -- --prompt "Добавь в FAQ вопрос про парковку" | pbcopy   # промпт в буфер обмена (macOS)
```

1. Вставьте промпт в ChatGPT, Gemini, Claude.ai, DeepSeek — куда угодно.
2. Ответ модели (JSON) сохраните в файл, например `answer.json`.
3. Примените: `npm run ai -- --response answer.json` — скрипт проверит правку, покажет изменения и спросит подтверждение.
   Если есть ошибки — ничего не сохранится; вставьте ошибки в тот же чат и попросите исправить.

**Вариант Б — совсем без терминала, через сайт GitHub:**

1. Откройте на github.com нужный файл, например `src/data/site.json`, и `schema/site.schema.json`
   (для страниц — `src/data/pages/home.json` и `schema/page.schema.json`; список типов блоков — `schema/README.md`).
   Для перевода: польский файл, текущий файл перевода (например `src/data/i18n/en/pages/home.json`) и раздел
   «Matching rules» из `docs/I18N.md`.
2. Скопируйте их в чат и напишите: «Вот JSON-схема и файл. Измени … Верни файл целиком, без пояснений».
3. В GitHub нажмите ✏️ у файла, замените содержимое ответом модели → **Commit changes** → *Create a new branch and start a
   pull request*.
4. Проверка CI в pull request покажет, всё ли правильно (если красная — откройте лог, скопируйте ошибку в чат). Затем **Merge**.

## Переводы: проверить, что не переведено

```bash
npm run i18n:status                    # таблица: сколько текстов переведено в каждом языке и файле
npm run i18n:status -- en --missing    # список непереведённых английских текстов: путь → польский текст
```

Непереведённый текст на сайте показывается по-польски — это не ошибка, сайт работает. Когда меняете польский текст,
меняйте и переводы (старый перевод сам не «устаревает» и в списке не появится).

## Если что-то пошло не так

- **Ошибка проверки контента** — текст ошибки говорит, что не так: `image "…" not found` (нет такого фото),
  `link "/#…" → no section with id` (ссылка на несуществующий блок), `… is disabled` (ссылка на скрытый блок),
  `use "/#…"` (в `site.json` ссылка на блок пишется с `/`), `Unrecognized key` (опечатка в названии поля),
  `"closes" … must be later than "opens"` (полночь — `"00:00"`), `product "…" does not exist` (опечатка в slug).
  В переводах: `unknown key` (такого ключа нет в польском файле), `… is not translatable` / `settings are not translated`
  (в перевод попала ссылка, фото, число или настройка — удалите), `item "…" does not exist in the default language`
  (в переводе блок или вкус с `id`/`slug`, которого нет в польском файле).
  MCP и `npm run ai` сами откатывают такие правки. Полный список ошибок с решениями: `docs/TROUBLESHOOTING.md`.
- **Сайт уже опубликован с ошибкой** — в GitHub откройте смерженный pull request → **Revert** → смержите возврат.
- **Проверить всё вручную:** `npm run content:check`, затем `npm run build`.
